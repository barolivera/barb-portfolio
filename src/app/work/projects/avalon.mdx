## The Problem

AI trading bots are black boxes. Retail traders deposit funds, can't see what happens, and lose money when the bot fails. Real cases: Clawdbot lost $1M, Lobstar Wilde lost $450K, a decimal error sent 40K SOL to the wrong address. All because there were no on-chain guardrails.

## The Solution

Avalon lets users build visual trading strategies with AI agents that have on-chain guardrails, public decision logs, and a fee model that only charges when profitable.

## How It Works

**Visual Strategy Builder** — A drag-and-drop interface connecting five components: Chainlink Price Feeds, Conditions, Actions, Risk Controls, and Fee Structure. One click deploys the strategy on-chain to Avalanche Fuji.

![Visual Strategy Builder](/images/projects/avalon/strategy-builder.png)

**AI Agent with On-Chain Identity (ERC-8004)** — Each agent is registered on an Identity Registry with a public reputation score. Users choose agents by verified track record, not marketing. Agents operate autonomously within strict user-defined limits.

**Platform Engagement Workflow** — Connect MetaMask → Build Strategy → Deploy → Activate → Pause → Withdraw. Every action is logged on-chain.

![Platform engagement workflow](/images/projects/avalon/workflow.png)
